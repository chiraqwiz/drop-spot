# DROP SPOT

A Facebook-inspired social app starter for the DROP SPOT brand.

## Tech stack
- Next.js
- TypeScript
- Tailwind CSS
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Included
- Responsive landing/feed UI
- Story row
- Post cards
- Sidebar navigation
- Chat panel
- Profile summary
- Friend requests
